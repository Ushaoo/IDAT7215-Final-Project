# 给数据评估与 Grad-CAM 同学

本GitHub分支提供 best_head.pt（分类头）、config.json、metrics.json、history.csv 和 test_predictions.csv。完整权重保存在许哲熙本地 M3_交付包.zip 中；仓库内的分类头配合官方 ImageNet V1 骨干可重建相同模型。

在交付包根目录使用：

```python
from PIL import Image
import torch
from m3.models import load_checkpoint, image_transform
model, metadata = load_checkpoint('m3/results/vgg16/best_head.pt', device='cpu')
with Image.open('example.jpg') as image:
    batch = image_transform()(image.convert('RGB')).unsqueeze(0)
with torch.inference_mode():
    p_defect = model(batch).softmax(1)[:, 1]
```

MobileNetV2 改成 mobilenet_v2 文件夹。首次加载仓库中的分类头需要联网下载对应官方 ImageNet V1 权重；后续会使用缓存。也可传 weights_dir 指向已下载的官方权重文件夹。

Grad-CAM 时不要用 inference_mode，设 batch.requires_grad_(True)。VGG16 可选 model.backbone[28]，MobileNetV2 可选 model.backbone[-1] 作为起点。

类别顺序固定为 [Non-defect, Defect]。预处理沿用 M4：RGB，直接缩放到224×224，ImageNet均值/标准差。扰动应在归一化前施加。
